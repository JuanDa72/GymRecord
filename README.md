# 🏋️ GymRecord API

A REST API built with **Java** and **Spring Boot** to help users track their gym progress.

This project focuses on the backend of the application, providing endpoints to manage workouts, exercises, and user progress. Although no frontend was developed, the API was designed to serve as the foundation for a complete fitness tracking application.

---

## ✨ Features

- 👤 User management
- 💪 Exercise management
- 📝 Workout registration
- 📊 Progress tracking
- 🔄 RESTful API architecture
- 🗄️ MySQL database integration

---

## 🛠️ Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

---

## 📂 Project Structure

```text
src
├── controller
├── service
├── repository
├── model
├── dto
└── config
```

The project follows a layered architecture to separate business logic, persistence, and API endpoints.

## 🚀 Getting Started

### Requirements

- Java 17+
- Maven
- MySQL

### Installation

```bash
git clone https://github.com/your-user/GymRecord.git

cd GymRecord
```

Configure your database credentials in:

```
application.properties
```
